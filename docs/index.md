# Bindle

Bindle is a stateless toolchain bridge with respect to your history,
knowledge, and transcripts — and durably owns one small thing of its own: a
repository-local coordination ledger tracking specified work.

- **New here?** Start with [Getting Started](site/getting-started.md) —
  provision Bindle in a disposable repository and run the real coordination
  flow end to end.
- **Want the mental model first?** Read
  [How Bindle Works](site/how-bindle-works.md) — what Bindle owns, what it
  hands off, and who decides when work is done.
- **Looking for deeper reference material?** Every existing architecture
  document — [Philosophy](PHILOSOPHY.md), [Scope](SCOPE.md),
  [Data Ownership](DATA-OWNERSHIP.md), [Symphony](SYMPHONY.md),
  [Worktrees](WORKTREES.md), [Privacy](PRIVACY.md),
  [Toolchain](TOOLCHAIN.md), and the [Decision Log](DECISIONS.md) — is
  reachable from the navigation above, rendered directly from its one
  canonical source.
